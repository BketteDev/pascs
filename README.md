# notCsSource

A browser shooter in the style of Counter-Strike: Source: three.js client, Node server running the game at 128 Hz over WebSockets,
bots, bomb / hostage modes, LAN play.

**No game content is included.** Maps, textures, models, sounds and fonts are converted from your own installs of Counter-Strike: Source,
CS:GO and Garry's Mod by the build tools, and stay on your machines (they are Valve's; don't commit or share them).

## Build the assets (Windows PC with the games installed)

```
npm install
npm run build        # maps, weapons, player models, sounds -> public/maps, public/weapons, public/players, public/sound, public/ui
```

Paths to the games are set in `tools/content.mjs` and `package.json`.

## Run locally

```
cp server.config.example.json server.config.json   # set map, team size, admin password (F4 menu)
npm start                                           # http://localhost:6767
npm test
```

## Deploy with Portainer

1. Copy the built asset folders `public/maps`, `public/sound`, `public/players`, `public/weapons`, `public/ui` to the Docker host,
   e.g. `/opt/notcssource/assets/{maps,sound,players,weapons,ui}`.
2. Portainer: **Stacks > Add stack > Repository**, this repo, compose path `docker-compose.yml`.
3. Environment variables: `ADMIN_PASSWORD` (required), and optionally `ASSETS_DIR` (default `/opt/notcssource/assets`), `MAP`
   (default `Source-Inferno`), `TEAM_SIZE` (default 5), `PORT` (default 6767).
4. Deploy, then open `http://<host>:6767`.

The server gzips map data on first request (cached in `.gzcache`) and revalidates files by ETag, so loads after the first are quick.
Weaker PCs: Options > Video > Render scale and Low texture quality.

## Incendiaries and utility

- Terrorists can buy a **Molotov ($400)**; CTs can buy an **Incendiary Grenade ($600)** from **B > Gear**.
- Carry up to four grenades in total, including at most one incendiary and two flashbangs.
- **4** cycles grenades, **6** selects smoke, **7** selects your incendiary. Hold/release left click for a full throw, right click for a short lob.
- Incendiaries ignite on walkable ground, bounce off walls and have a 3.5-second maximum fuse. Ground fire spreads for 7 seconds and deals 40 HP/s, bypassing armor. It hurts enemies and the thrower; teammates are protected.
- Fire follows the floor and is blocked by walls. Nearby smoke extinguishes it and prevents re-ignition while the cloud lasts. New rounds clear all fire and smoke.
- Bottle/canister models, flame effects and HUD icons are generated by the client, so existing asset folders do not need rebuilding.

`npm test` runs physics, ballistics, deterministic incendiary checks and WebSocket integration tests. On a machine that blocks loopback connections, `npm run test:offline` runs the same game scenarios with an in-process transport; this does not test the actual WebSocket connection.

## Local ZIP additions: Mirage and RPG-7

`zip ajout a faire/mapcs.zip` is imported as **de_mirage_csgo_new**. Select it in Server Admin; the current default map stays unchanged. It includes both bombsites, collision, the embedded radar and generated bot navigation. Some decorative props depend on HL2 models absent from the local content and are omitted by the existing converter.

Buy the **RPG-7 ($6000)** from **B > Heavy** on either team. It replaces the primary weapon: **1** selects it, left click fires, **R** reloads. It has one loaded rocket and four spare rounds, with a 5.1-second reload. Rockets fly straight and explode against players or geometry; walls block blast damage, teammates are protected, and the shooter can take splash damage. The launcher, missile, textures, animations, sounds and icon come from `rocket.zip`. SourceMod binaries are not used by this browser game. Ammunition and reloads are validated by the server, together with projectile ownership, firing cadence, collision and damage.

To regenerate only these additions after extracting the ZIPs into `exports/asset-import/{mapcs,rocket}`, run from `web`:

```powershell
node tools/weapons.mjs --rocket
node tools/build.mjs de_mirage_csgo_new --bsp "../exports/asset-import/mapcs/MIRAGE MAP/de_mirage_csgo_new.bsp"
```

The existing cosmetic packs do not need importing again. Restart the Node server and reload the game after updating the files.

## Vérification locale des ajouts

Redémarrer Node après un changement du code serveur : changer seulement la carte via Server Admin conserve les anciens modules en mémoire. C’était la cause du RPG-7 visible dans le menu mais ignoré par le serveur. `test-buy.mjs` couvre le clic sur le secteur RPG, son message, l’achat, l’équipement et le snapshot. Le prix exact et la limite de temps d’achat restent appliqués.

Cinq cages de Mirage étaient associées dans le BSP à `shell_pallet` (base seule) plutôt qu’à `bomb_shells_1_metal` ou `bomb_shells_2_metal`. La conversion y réutilise les modèles complets du pack et conserve les cages en bois : les neuf emplacements contiennent maintenant les obus. Aucun changement d’alpha ou de culling.

Les volumes `CONTENTS_LADDER` du BSP ou les échelles du VMF sont conservés séparément des collisions solides. Le mouvement et l’état d’attachement sont partagés et synchronisés entre client et serveur. Avancer face à l’échelle fait monter, reculer fait descendre, relâcher immobilise ; le déplacement latéral et le saut détachent. La sortie en haut vérifie le passage du volume complet du joueur vers un palier proche. Référence : [LadderMove du Source SDK](https://github.com/ValveSoftware/source-sdk-2013/blob/master/src/game/shared/gamemovement.cpp).

`node tools/import-ladders.mjs` actualise uniquement les métadonnées des cartes existantes ; les convertisseurs BSP et VMF les produisent aussi. Tests par simulation sur les collisions réelles :

| Carte | Échelles détectées et testées |
|---|---:|
| cs_office | 2 |
| de_bank | 7 |
| de_lake | 4 |
| de_mirage_csgo_new | 2, sorties en haut également testées |
| de_nuke | 4 |
| de_overpass | 1 |
| de_shortdust | 1 |
| cs_agency, cs_italy, de_dust2, de_inferno, de_shortnuke | 0 dans les sources examinées |

`npm test` inclut l’achat, les mouvements d’échelle, les 21 volumes réels, les caisses et les tests WebSocket. Le contrôle visuel de Brave a été bloqué par l’outil, qui ne pouvait pas vérifier son URL ; la validation visuelle en partie reste à faire.

## Bots faciles et dégâts du RPG-7

Le RPG-7 coûte maintenant **6 000 $**, prix partagé par le menu et la validation serveur. Les bots attendent 1,0 à 1,4 seconde après détection (0,8 à 1,2 seconde après avoir été attaqués), contre 0,5 à 0,75 / 0,4 à 0,65 seconde auparavant. Leur dispersion supplémentaire passe de 0,035 à 0,075 et ils visent le torse. Déplacements, navigation, objectifs, rechargements et utilisation des grenades sont conservés.

L’explosion du RPG-7 existait déjà : rayon de **350 unités**, dégâts bruts de **140 × (1 − distance / 350)** avant armure, mesurés au torse. Un tir de test contre un mur blesse simultanément deux ennemis hors de sa trajectoire : **104,53 et 39,70 PV**. Le test vérifie aussi la décroissance, un ennemi derrière un mur, un ennemi hors rayon, la protection des coéquipiers et les dégâts au tireur. `node test-rockets.mjs` exécute ce scénario sur le vrai serveur avec une horloge déterministe.

Pour GitHub, les géométries de Mirage et Agency dépassent 100 Mio à l’état brut. Elles sont publiées sans perte en `world.bin.gz` ; le serveur répond toujours à l’URL habituelle `world.bin`, avec décodage transparent pour les navigateurs et décompression serveur pour les clients sans gzip. `node test-static.mjs` vérifie ce chemin et le cache ETag. Les convertisseurs produisent aussi ces fichiers compressés lors des prochains builds. Les archives sources et le mot de passe local ne sont pas publiés.


## Chargement, connexion et commandes

Le chargement affiche l’étape et le temps écoulé, avec un bouton **Réessayer / Retry**. Une erreur HTTP, un modèle manquant ou une erreur de démarrage affiche un message ; les textures manquantes reçoivent une texture de secours. Les textures encore en cours après 15 secondes continuent de charger en arrière-plan.

Le client réessaie automatiquement après une coupure (délai progressif de 0,5 à 5 secondes), y compris au retour d’arrière-plan. Le serveur réserve la place pendant **30 secondes** et conserve l’équipe, le score, l’argent et les armes grâce à un jeton propre à l’onglet. Le personnage reste présent et vulnérable ; la bombe est lâchée et une pose/un désamorçage en cours est interrompu. Après expiration, le joueur revient comme spectateur et peut rejoindre une équipe. Une exclusion ne déclenche pas de reconnexion. Un changement de carte recharge la page.

Les chargeurs, réserves et délais de rechargement sont contrôlés par le serveur. Changer d’arme interrompt un rechargement ; les fusils à pompe chargent cartouche par cartouche et peuvent interrompre le chargement pour tirer. Une arme ramassée conserve ses munitions. Le client affiche immédiatement ses tirs et se recale sur les actions confirmées par le serveur. Les survivants sont réapprovisionnés au début de chaque manche, comme auparavant.

Le menu **Guide / How to play** présente les objectifs et les commandes et s’affiche avant la première partie. **Options → Keyboard** propose AZERTY et QWERTY ainsi que les touches individuelles. Les positions physiques de déplacement restent identiques ; leurs lettres affichées suivent la disposition choisie. Le français sélectionne AZERTY par défaut si aucune préférence n’est enregistrée.

Dans **Options → Touch**, régler la taille des boutons ou ouvrir **Déplacer les boutons / Edit layout**. Glisser les boutons, puis enregistrer. Annuler abandonne les changements ; réinitialiser prépare les positions d’origine. Les dispositions portrait et paysage sont enregistrées séparément. Tourner le téléphone pendant l’édition annule l’édition en cours.

## Réseau et difficulté des bots

La simulation reste à **128 Hz**. Par défaut, les états réseau sont envoyés à **32 Hz**, avec les événements accumulés entre deux envois et une interpolation adaptée. Un client dont la connexion est saturée ne reçoit pas une file illimitée d’anciens états ; les événements en attente sont bornés à 512. Le débit exact dépend du nombre de joueurs et des événements.

**Server Admin** propose les difficultés **Facile / Normal / Difficile** (temps de réaction et dispersion) et les fréquences réseau **16 / 32 / 64 / 128 Hz**. Facile conserve les bots faciles de la version précédente. Appliquer ces réglages redémarre la partie pour tous les joueurs.

Les mêmes paramètres sont disponibles dans `server.config.json` :

```json
{
  "botDifficulty": "easy",
  "snapshotRate": 32
}
```

Ou via les variables `BOT_DIFFICULTY=easy|normal|hard` et `SNAPSHOT_RATE=16|32|64|128`, également exposées dans Docker Compose. Redémarrer Node après une modification du code serveur.

## Vérifications sur Termux

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run test:offline
node test-static.mjs
```

Le sol artificiel de `test-physics.mjs` est limité à 8 192 unités de chaque côté pour éviter des millions de cellules de collision inutiles et une saturation mémoire sur téléphone. Les tests s’exécutent successivement. `test-gameplay.mjs` couvre les munitions, réserves, rechargements, armes ramassées, fréquences réseau et réservations de session avec une petite carte et une horloge déterministe. `test-net.mjs` vérifie la reconnexion du client, les confirmations d’actions et les dispositions clavier ; `test-weapons.mjs` exerce le vrai contrôleur d’armes sans GPU. `npm test` utilise aussi le véritable transport WebSocket ; le mode offline utilise un transport en mémoire.

La disposition tactile et le rendu WebGL demandent encore une vérification visuelle dans le navigateur du téléphone.

Les dossiers, les listes Admin, le tableau des scores et le titre de la page utilisent désormais les mêmes noms :

| Source | CS:GO |

| Source-Inferno | GO-Agency |
| Source-Nuke | GO-Italy |
| Source-Office | GO-Lake |
| | GO-Mirage |
| | GO-Overpass |
| | GO-ShortDust |

Le registre partagé est `public/maps.js`. Les sélecteurs affichent uniquement les dossiers canoniques de la catégorie choisie, même si un ancien serveur renvoie des alias en doublon. Les anciens identifiants des cartes actives (`cs_office`, `de_mirage`, `de_mirage_csgo_new`, etc.) restent acceptés dans `MAP`, la configuration, l’API Admin et les URL des ressources.

`GO-Bank` et `Source-Dust2` sont désactivées : absentes des listes, refusées par l’API Admin et au démarrage, ressources HTTP en statut 410. Leurs fichiers et sources restent conservés. Les configurations existantes utilisant l’une de ces cartes doivent choisir une carte active ; le nouveau défaut est `Source-Inferno`.

Italy, Overpass et ShortDust ont été reconstruites avec les overlays projetés et découpés sur leurs faces de support, les UV de relief calculés sur la surface plane d’origine et sans simplification des modèles fins (bordures, végétation, grilles, barrières). Le ciel partage toujours l’orientation de la caméra du jeu, y compris sans ciel 3D. `npm run test:rendering` vérifie ces conventions sans GPU.

Les conventions ont été comparées aux sources Valve : [rotations Source](https://github.com/ValveSoftware/source-sdk-2013/blob/master/src/mathlib/mathlib_base.cpp), [plans et axes des faces VMF](https://github.com/ValveSoftware/source-sdk-2013/blob/master/src/utils/vbsp/map.cpp) et [caméra du ciel 3D](https://github.com/ValveSoftware/source-sdk-2013/blob/master/src/game/client/viewrender.cpp).

Limites des ressources disponibles : Overpass référence encore `models/props_equipment/metal_ladder002_new.mdl` et `models/props_canal/canal_bars00{1,2,3}.mdl`, absents des sources installées ; les garde-corps `props_mill/stair_railing_{long,short}.mdl` utilisent toujours une substitution Inferno aux dimensions différentes. Leur restauration fidèle reste nécessaire. Des matériaux de remplacement et des modèles absents subsistent également sur Italy et ShortDust. Les tests structurels ne prouvent pas la fidélité visuelle de ces éléments.

Pour terminer Overpass, il faut les ressources **Source 1** correspondant aux VMF de ce projet (décompilation datée du 20 octobre 2018) : `csgo/pak01_dir.vpk` avec ses segments `pak01_*.vpk`, ou les six modèles ci-dessous extraits avec leurs fichiers `.vvd`, `.dx90.vtx`, `.phy` lorsqu’ils existent, et leurs matériaux `.vmt`/`.vtf` référencés :

- `models/props_equipment/metal_ladder002_new.mdl`
- `models/props_canal/canal_bars001.mdl`
- `models/props_canal/canal_bars002.mdl`
- `models/props_canal/canal_bars003.mdl`
- `models/props_mill/stair_railing_long.mdl`
- `models/props_mill/stair_railing_short.mdl`

Ces noms ont été recherchés dans le contenu local, l’archive CS:S et le VPK CS2 installé : aucun original utilisable. La distribution [officielle CS:GO sur Steam](https://store.steampowered.com/app/4465480/CounterStrike_Global_Offensive/) est une provenance à vérifier pour les ressources Source 1 ; sa présence sur Steam ne garantit pas qu’elle conserve ces variantes de 2018. La matrice de rotation de l’exporteur correspond à celle de Valve : aucune rotation arbitraire n’a été ajoutée pour masquer le mauvais remplacement de garde-corps. Le contrôle visuel effectué porte sur le chargement d’Italy dans un navigateur ; les six défauts de ressources ci-dessus restent ouverts.

## Téléphone et accessibilité

Les nouveaux joueurs sur téléphone démarrent avec un rendu à 75 %, des textures allégées et des chiffres lisibles ; les préférences déjà enregistrées sont conservées. **Options → Touch → Réglages conseillés pour téléphone** applique ce profil aux joueurs existants (les textures changent après rechargement de la page).

Le mode tactile simplifié affiche les actions principales et range scores, équipe, discussion, lâcher et inspecter dans **Plus**. Les pistolets peuvent tirer en continu en maintenant **Tirer**, à leur cadence normale. Le rechargement démarre automatiquement à vide. Ces deux aides et le mode simplifié sont désactivables dans les options. Le retour d’arrière-plan libère les touches et l’accroupissement.

Sur téléphone, le magasin utilise de grandes cartes tactiles et affiche les prix, les achats indisponibles et un bouton **Équipement conseillé** qui détaille son coût et son contenu avant achat. La sélection d’équipe propose **Jouer · équipe automatique**.

**Options → Accessibilité** propose textes/cibles agrandis, contraste renforcé, chiffres standards, réduction des transitions et des clignotements, et un flash sombre qui conserve la durée et l’opacité de l’aveuglement. La préférence système de réduction des mouvements est également respectée. Les menus et les commandes principales peuvent être activés au clavier, avec un indicateur de focus visible. Le bouton de reprise du chargement reprend le style VGUI olive du reste du jeu.

`npm run test:ui` vérifie les interactions DOM mobiles sans navigateur ni GPU : achats, budget conseillé, commandes tactiles, reprise après arrière-plan, sélection d’équipe et noms des cartes. `linkedom` est uniquement une dépendance de développement ; l’image de production continue d’installer les dépendances avec `--omit=dev`. Les tests HTTP couvrent aussi les noms canoniques et la compatibilité des anciens noms.

## Vérification des cartes sous Termux

`npm run test:maps` contrôle les 12 cartes, chacune dans un processus séparé pour libérer sa mémoire avant la suivante. Il vérifie les fichiers de géométrie (y compris les `.bin.gz`), les valeurs et plages des attributs, les références de textures avec leur casse exacte, les apparitions avec la physique du jeu, les points de navigation et l’accès aux sites de bombe ou de sauvetage. `node tools/audit-maps.mjs GO-Agency` produit le diagnostic JSON d’une seule carte. Ces contrôles ne remplacent pas une vérification visuelle WebGL dans le navigateur.

Les otages d’Agency proches des meubles apparaissent désormais au sol, dans un espace libre, au lieu d’être remontés sur les meubles. Le serveur et le convertisseur VMF partagent cette recherche de position sûre, qui tient aussi compte des collisions réservées aux joueurs. Les caches de navigation d’Agency, Italy et Overpass ont été nettoyés des points dans des obstacles. Le serveur valide également les caches chargés ; les portes utilisables et vitres cassables restent des passages possibles. La descente à sens unique de l’hélipad d’Agency est conservée.
